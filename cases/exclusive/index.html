Задача
Редизайн текущего сайта

Сделать редизайн текущего сайта с учетом уже построенной бизнес логикой.

Современный Максимальная открытость и доверие для пользователя

Проблема
Сложность восприятия
  • Проблема информационной архитектуры (восприятие контента затруднительное из-за сплошного текста
  • и не видимых элементов интерфейса)
  • Точки трения при оформлении заказа (20% пользователей в вебвизоре демонстрируют проблему обнаружения следующего шага), долгая вторизация
  • Недостаточность визуального веса (некоторые информационные блоки не видемы для пользователя)
Моя роль
Проектирование UX/UI
  • Провела UX-аудит (вебвизоре) и выявила «точки трения».
  • На основании аудита сформулировала и предложила варианты решения проблемы точки трения. 
  • Спроектировала *новую информационную архитектуру* для второстепенных сценариев (Главная страница, доставка, оплата)
  • На всех этапах тесно взаимодействовала с разработчиками (ux/ui designer я одна), согласовывая возможности технической реализации
Результат
Полный редизайн
  • Редизайн интернет-магазина с учётом бизнес-логики (более 30+ экранов + mobile). Результат: сократила время входа в ЛК на 10% (упростила форму регистрации, по итогу анализа добавила вход через №тел, это помогло увеличить регистрацию новых пользователей на 3%. Визуально дизайн стал привлекательнее и удобнее.
  • Разработала доп. функционал “Напоминание о записи через смс” (десктоп+моб. версия). Результат: эти экраны сократили нагрузку на колл-центр на 15% + пользователю удобно.
